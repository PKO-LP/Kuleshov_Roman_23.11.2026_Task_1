# Приём заявок — версия 0.3.1

## Состав папки
app.py — программа; logo.png — обязательная картинка; Передача_программы — документация.

## Подготовка
Нужен Python 3 с Tkinter. Сторонние библиотеки не требуются. Полностью распакуйте комплект. app.py и logo.png должны лежать рядом.

## Запуск
- VS Code → File → Open Folder… → откройте саму папку Комплект_0_3_1.
- Terminal → New Terminal. Терминал должен находиться в Комплект_0_3_1.
- Windows: python app.py (если python не найден — py app.py). Mac/Linux: python3 app.py.
- Ожидается окно «Приём заявок 0.3.1».

## Проверка
С нового запуска примите одну заявку: количество 1, показана дата. После сброса примите 10: «Лимит: 10», приём недоступен. Полный сброс: количество 0, дата —, статус Новая, закрыто 0. Статусы идут Новая → В работе → Готово → Новая.

## Если окно не открылось
Сохраните полный текст ошибки. Проверьте Python с Tkinter и наличие logo.png рядом с app.py. При ошибке среды Tkinter сначала восстановите запуск среды, затем повторите проверку программы.

## Ограничения
Счётчики не сохраняются после закрытия. Нет списка отдельных заявок, авторизации и базы данных. «Закрыто» считает переходы общего статуса в Готово.
